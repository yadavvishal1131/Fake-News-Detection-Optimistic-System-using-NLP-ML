# Fake News Detection & Optimistic System using NLP & ML

## Project Overview
This project uses Natural Language Processing (NLP) and Machine Learning techniques to classify news articles as Fake or True.

## Features
- Text preprocessing and cleaning
- TF-IDF vectorization
- Machine Learning classification
- Streamlit web application
- Real-time prediction

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Streamlit
- Matplotlib
- Seaborn

## Dataset
- Fake.csv
- True.csv

## Project Structure
├── app.py
├── main.ipynb
├── model.pkl
├── vectorizer.pkl
├── Fake.csv
├── True.csv
└── confusion_matrices.png
